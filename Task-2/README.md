# Task 2 — Reproducible Research Question & Analysis Preregistration

## Objective

The objective of this task is to convert an interesting dataset into a falsifiable research question and define the analysis plan before inspecting outcome patterns.

## Main Activities

* Define the research population.
* Define the exposure or intervention.
* Define the comparator.
* Define the outcome.
* Define the observation window.
* Formulate research hypotheses.
* Define exclusion rules.
* Define data transformations.
* Define statistical tests and effect sizes.
* Define robustness checks.
* Create a reproducible research repository.
* Create a reproducible environment.
* Test the analysis pipeline using synthetic data.
